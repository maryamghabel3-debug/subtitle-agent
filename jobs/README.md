# پوشه اختیاری برای فایل‌های کوچک هر کار

اگر نمی‌خواهی از Release یا لینک استفاده کنی، فقط فایل‌های کوچک زیر را می‌توانی این‌جا در یک زیرپوشه برای هر ویدیو بگذاری:

```text
jobs/<job-name>/<job-name>.fa.srt
jobs/<job-name>/<job-name>.cuts.txt
```

بعد همان مسیرها را در ورک‌فلوی **02 ساخت خروجی نهایی و قسمت‌ها** در ورودی‌های `fa_srt_path` و `cuts_path` بنویس.

ویدیو را این‌جا آپلود نکن؛ برای ویدیو از لینک درایو/مستقیم، پیوست Release یا Colab استفاده کن. راهنمای کامل: [`../docs/AUTOMATION_FA.md`](../docs/AUTOMATION_FA.md).

> اگر ریپو Public باشد، فایل‌های این پوشه هم عمومی‌اند.
