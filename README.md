# 🎬fa-subtitle-pipeline | زیرنویس فارسی + برش ریلز/شورتس

ابزار خودکار برای ویدیوهایی که **زیرنویس انگلیسی چسبیده (Hardcoded)** دارند:

1. زیرنویس انگلیسی را یا از فایل آماده (مثلاً خروجی **Subtitle Edit**) می‌گیرد، یا با **Whisper** از روی صدا می‌سازد.
2. به فارسی ترجمه می‌کند — فعلاً بدون API (**حالت دستی**)، بعداً با یک تنظیم ساده به API وصل می‌شود.
3. زیرنویس فارسی را با فونت **وزیرمتن** روی ویدیو می‌چسباند؛ زیرنویس انگلیسی سر جایش می‌ماند (خروجی **دوزبانه**، فارسی بالای انگلیسی).
4. ویدیو را **هوشمند** به قسمت‌های ~۶۰ ثانیه‌ای می‌بُرد (برش روی پایان جمله، نه وسط جمله) + نسخه کامل برای یوتیوب.

**ابعاد خروجی خودکار مثل خود ویدیو است** — عمودی ۹:۱۶ می‌ماند عمودی، افقی می‌ماند افقی. (تبدیل به بوم ۹:۱۶ با پس‌زمینه تار هم با `--output-mode vertical` ممکن است.)

```
ویدیو ─┬─ (--en-srt آماده) ──────────────┐
       └─ (Whisper از روی صدا) ──────────┤
                                          ▼
                              زیرنویس انگلیسی (.srt)
                                          ▼
                        ترجمه: manual ✋ | google | openai
                                          ▼
                               زیرنویس فارسی (.srt)
                                          ▼
              چسباندن با FFmpeg+libass (فونت وزیرمتن، بالای انگلیسی)
                          ┌───────────────┴───────────────┐
                   نسخه کامل یوتیوب              قسمت‌های ~۶۰ ثانیه‌ای
                   <نام>_full_fa.mp4              parts/<نام>_part-01.mp4 ...
```

## 🚀 نصب

**نیازمندی‌ها:** پایتون ۳.۱۰ به بالا + [FFmpeg](https://ffmpeg.org/download.html) (نسخه دارای `libass`)

| سیستم | نصب FFmpeg |
|---|---|
| ویندوز | `winget install Gyan.FFmpeg` یا دانلود از [gyan.dev](https://www.gyan.dev/ffmpeg/builds/) و افزودن به PATH |
| مک | `brew install ffmpeg` |
| لینوکس | `sudo apt install ffmpeg` |

نصب خود ابزار:

```bash
git clone https://github.com/YOUR_USERNAME/persian-subtitle-pipeline.git
cd persian-subtitle-pipeline

pip install -e .                # هسته اصلی (کافی برای شروع با فایل srt آماده)
pip install -e ".[whisper]"    # اختیاری: ساخت زیرنویس از روی صدا
pip install -e ".[google]"     # اختیاری: ترجمه رایگان گوگل

fa-subs doctor                  # بررسی آماده بودن همه‌چیز ✅
```

> فونت وزیرمتن همراه ریپو در پوشه `fonts/` هست؛ نیازی به نصب روی سیستم نیست.

## 📖 روش استفاده

### روش ۱ — زیرنویس انگلیسی آماده دارید + ترجمه دستی (شروع پیشنهادی)

این همان حالتی است که فعلاً با هم جلو می‌رویم: زیرنویس انگلیسی را با Subtitle Edit گرفته‌اید و ترجمه را دستی انجام می‌دهید (خودتان یا فایل را در چت به یک دستیار هوش مصنوعی می‌دهید و ترجمه آماده تحویل می‌گیرید).

```bash
fa-subs run video.mp4 --en-srt video.en.srt
```

اجرای اول وسط کار در **ایستگاه ترجمه** متوقف می‌شود (کد خروج ۲) و یک قالب آماده در `output/<نام ویدیو>/work/<نام ویدیو>.fa.srt` می‌سازد: زمان‌بندی‌ها درست‌اند، فقط متن‌ها باید فارسی شوند.

ترجمه را در همان فایل جایگذاری کنید (تعداد خطوط و زمان‌ها را تغییر ندهید) و دوباره **همان دستور** را اجرا کنید؛ کار از همان‌جا ادامه پیدا می‌کند و ویدیوهای نهایی ساخته می‌شوند.

اگر فایل ترجمه‌شده را جای دیگری دارید:

```bash
fa-subs run video.mp4 --en-srt video.en.srt --fa-srt ترجمه_من.fa.srt
```

### روش ۲ — فایل زیرنویس ندارید (Whisper از روی صدا)

```bash
pip install -e ".[whisper]"
fa-subs run video.mp4                 # اول Whisper، بعد ایستگاه ترجمه دستی
fa-subs run video.mp4 --provider google   # با ترجمه خودکار رایگان گوگل
```

> روی سیستم بدون کارت گرافیک NVIDIA، مدل پیش‌فرض `small` روی CPU کار می‌کند ولی برای ویدیوی طولانی کند است؛ در این حالت یا فایل srt آماده بدهید یا از [نوت‌بوک Colab](notebooks/colab.ipynb) استفاده کنید.

### روش ۳ — بعداً که کلید API گرفتید (ترجمه خودکار باکیفیت)

هیچ تغییری در کد لازم نیست:

```bash
# لینوکس/مک
export OPENAI_API_KEY=sk-...
# ویندوز (PowerShell)
$env:OPENAI_API_KEY='sk-...'

fa-subs run video.mp4 --en-srt video.en.srt --provider openai
```

مدل و آدرس API در کانفیگ قابل تغییرند؛ یعنی OpenAI، OpenRouter، Groq یا هر سرویس OpenAI-compatible دیگری هم کار می‌کند (`translation_model` و `translation_api_base`).

### دستورهای فرعی

```bash
fa-subs transcribe video.mp4 --out video.en.srt     # فقط ساخت زیرنویس از صدا
fa-subs translate video.en.srt --out video.fa.srt --provider google
fa-subs burn video.mp4 --fa-srt video.fa.srt --out out.mp4   # فقط چسباندن، بدون برش
fa-subs doctor                                       # عیب‌یابی محیط
fa-subs run --help                                   # همه گزینه‌های دستور اصلی
```

## 📂 ساختار خروجی

```
output/<نام ویدیو>/
├── <نام>_full_fa.mp4          ← نسخه کامل برای یوتیوب
├── parts/
│   ├── <نام>_part-01.mp4      ← قسمت‌ها برای ریلز / شورتس
│   └── <نام>_part-02.mp4
├── captions.txt               ← قالب آماده کپشن برای هر قسمت
├── manifest.json              ← مشخصات و زمان‌بندی قسمت‌ها
└── work/                      ← فایل‌های میانی (کش؛ اجرای دوباره از اول شروع نمی‌کند)
    ├── <نام>.en.srt / .fa.srt / .fa.ass
    └── subtitle_warnings.txt  ← خطوطی که برای خواندن طولانی‌اند (اگر بود)
```

## ⚙️ تنظیمات مهم

همه تنظیمات در [`config.example.yaml`](config.example.yaml) با توضیح فارسی هست. کپی‌اش کنید به `config.yaml` و با `--config config.yaml` استفاده کنید. مهم‌ترین‌ها:

| تنظیم | کاربرد |
|---|---|
| `part_duration: 60` | طول هدف هر قسمت (مثلاً ۹۰ یا ۱۲۰ برای ریلز ۲ دقیقه‌ای) |
| `position: "above_english"` | فارسی بالای انگلیسی بماند (دوزبانه)؛ گزینه‌های دیگر: `bottom` و `top` |
| `margin_v` | اگر فارسی روی انگلیسی افتاد، این عدد (پیکسل) را بیشتر کنید |
| `font_size` | اندازه فونت؛ خالی یعنی خودکار بر اساس ارتفاع ویدیو |
| `output_mode: "original"` | ابعاد خود ویدیو؛ `vertical` یعنی بوم ۹:۱۶ تار، `horizontal` بوم ۱۶:۹ |
| `translation_style` | لحن ترجمه در حالت openai (مثلاً «محاوره‌ای و خودمانی») |

بیشتر این‌ها را روی خط فرمان هم می‌شود داد، مثلاً:
`fa-subs run v.mp4 --fa-srt f.fa.srt --part-duration 90 --no-full`

## 🧪 اجرای دمو بدون ویدیوی واقعی

در پوشه `examples/` یک زیرنویس نمونه انگلیسی/فارسی (۱۲ ثانیه) هست. با هر ویدیوی کوتاهی می‌توانید کل مسیر را امتحان کنید:

```bash
fa-subs run تست.mp4 --en-srt examples/sample.en.srt --fa-srt examples/sample.fa.srt
```

## ❓ عیب‌یابی

- **حروف فارسی جدا یا برعکس دیده می‌شوند** → نسخه FFmpeg شما `libass` ندارد؛ `fa-subs doctor` را بزنید و FFmpeg استاندارد نصب کنید.
- **فارسی روی زیرنویس انگلیسی می‌افتد** → `margin_v` را در کانفیگ بیشتر کنید (مثلاً برای ویدیوی عمودی ۱۰۸۰×۱۹۲۰ حدود ۲۴۰). اگر انگلیسی پایین‌تر/بالاتر از معمول است، `--position top` هم گزینه خوبی است.
- **`ffmpeg پیدا نشد`** → نصب کنید یا مسیرش را با `ffmpeg_path` در کانفیگ بدهید.
- **فایل srt از Subtitle Edit به‌هم‌ریخته خوانده می‌شود** → هنگام خروجی گرفتن انکودینگ را روی UTF-8 بگذارید (ابزار cp1256 را هم تحمل می‌کند، ولی UTF-8 مطمئن‌تر است).
- **خط تغییر کرده ولی خروجی قدیمی می‌آید** → یک بار با `--force` اجرا کنید تا کش نادیده گرفته شود.
